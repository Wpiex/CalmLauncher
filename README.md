# Calm Launcher

Calm Launcher is an independent third-party launcher for Minecraft: Java Edition.

## Features

- Microsoft account authentication
- Minecraft: Java Edition profile integration
- Minecraft version management
- Mod loader support
- Instance management

## Microsoft Account Authentication

Calm Launcher uses the official Microsoft authentication flow for users who own Minecraft: Java Edition.

The launcher does not bypass Minecraft ownership, licensing, or authentication requirements.

## Status

Calm Launcher is currently in development.
